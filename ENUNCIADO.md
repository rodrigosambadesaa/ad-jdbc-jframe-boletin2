# Enunciado / material de partida — Boletín 2 Swing

La entrega recuperada de **Acceso a Datos (2018)** contiene 16 ejercicios independientes de interfaz gráfica Java/Swing:

1. Crear una minicalculadora.
2. Calcular el valor absoluto de un número.
3. Calcular el factorial de un número.
4. Calcular una potencia.
5. Obtener la longitud de una cadena.
6. Comprobar si la suma de dos valores supera 10.
7. Clasificar un número como positivo, negativo o cero.
8. Comparar dos caracteres.
9. Comprobar si un número pertenece al intervalo `[10, 100]`.
10. Mostrar las potencias de 2 para exponentes entre 0 y 10.
11. Mostrar los múltiplos de 4 hasta un valor `N`.
12. Mostrar un saludo mediante cuadro de diálogo.
13. Crear una encuesta sencilla.
14. Gestionar una lista de alumnos.
15. Gestionar dos listas permitiendo transferir alumnos entre ellas.
16. Crear un selector de color.

El repositorio reúne todos los ejercicios en una implementación revisable y moderna. No existe una base de datos asociada a este boletín.

> El conjunto recuperado en Drive contiene los proyectos resueltos, pero no se ha localizado un PDF independiente que permita reproducir literalmente un enunciado más extenso; por ello este archivo documenta los 16 objetivos verificables de la entrega.
